# Platform glossary

Canonical English terms, accepted aliases, and the Italian translation
the platform should generate for each, for the Digital Twin Agent
(`app.utils.knowledge`) and for the `lookup_glossary` tool. Every term in
this directory is read the same way, regardless of subject: platform
concepts, the territorial-indices framework's own vocabulary, and each
individual index are all just `GlossaryTerm` entries that link to each
other via `related_terms`.
