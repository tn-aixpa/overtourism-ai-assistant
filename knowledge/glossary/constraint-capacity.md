# Constraint capacity

The maximum acceptable value for a specific constraint before it is considered violated. A constraint capacity may refer to the number of visitors, parked cars, accommodation occupancy, restaurant demand, beach attendance, or any other resource or parameter used in the simulation. We can measure if a constraint is exceeded or not using Criticality index.


## Examples

- Maximum number of visitors in the historic centre.
- Maximum parking occupancy.
- Maximum beach attendance.
